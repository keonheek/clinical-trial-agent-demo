환자 선택

왼쪽에서 환자를 선택하세요.

각 기준에는 두 가지가 표시됩니다. 적격성 효과(PASS, FAIL, REVIEW)는 참여 가능 여부에 미치는 영향이고, 그 옆의 조건 판정(MET, NOT_MET, UNKNOWN)은 기준 문장이 환자에게 해당하는지만 나타냅니다. 제외 기준의 조건 판정이 MET이면 환자가 그 조건을 가지고 있다는 뜻이므로 적격성 효과는 FAIL이 됩니다.

확인 질문

본 결과는 의학적 자문이 아닌 참고용입니다. 답변을 입력하면 실제 LLM 호출로 영향받는 기준만 재평가됩니다. 이 데모는 10명의 사전 등록된 환자만 지원합니다. 데이터 출처 ClinicalTrials.gov API v2 (미국 NLM/NIH, 공공저작물) · 환자 = 대회 제공 합성 vignette · LLM 백엔드 = Anthropic (대회 지원 크레딧)
